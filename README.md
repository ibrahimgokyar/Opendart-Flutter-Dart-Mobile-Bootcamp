# Flutter ile Mobil Uygulama Geliştirme Eğitimi

Flutter, Google tarafından geliştirilen açık kaynaklı bir UI toolkit / SDK yapısıdır. Dart programlama dili ile tek kod tabanı üzerinden Android, iOS ve web uygulamaları geliştirmeyi sağlar.

Opendart Akademi Flutter eğitimi; modern mobil uygulama geliştirme süreçlerini proje tabanlı olarak öğretmek için hazırlanmıştır.

Katılımcılar eğitim sürecinde:

- Dart programlama dili
- Flutter widget yapısı
- responsive ve adaptive UI
- state management
- REST API entegrasyonu
- Firebase kullanımı
- Hive / local storage
- Android ve iOS deployment
- gerçek proje geliştirme

konularında uygulamalı deneyim kazanır.
